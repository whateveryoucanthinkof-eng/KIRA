## What was wrong, and is now fixed

Ordered by how badly each would have corrupted a result.

| defect | effect | fix |
|---|---|---|
| **Heuristic label override** | 98.2% of the held-out test's positives were fabricated by a heuristic; CIC-2017 Monday (zero attacks) labelled 14% attack | off by default (`CYBERWORLD_HEURISTIC_LABEL_OVERRIDE`) |
| **Hosts merged across captures** | same IP in two captures = one trajectory; all 350 fabricated CIC-2018 hosts merged across days; 2018 rows preceded 2011 rows | `TrajectoryStoreBuilder.set_namespace`, one trajectory per (host, capture) |
| **Models were time-blind** | 40.9% of 19.9M targets lie >10 s from their history (CTU-13 median 736 s); no model could tell 2 s from 2 h | real elapsed time wired into Branch A (new zero-init channel), Branch B, DeepOP and both serving paths — **no samples dropped** |
| **Window clock drifted after gaps** | 96.7% of one capture's windows held records outside their own bounds; hazard target 3.2x too low | clock advances to the containing grid cell |
| **Detector could never alert on lateral movement** | internal-only traffic capped at 0.40 against a 0.65 threshold | warns loudly at startup; a fitted operating point (~0.26) makes it reachable |
| Risk head worse than predicting zero | mean-seeking loss vs median-seeking metric on a bimodal target | Branch A: bce; Branch B: Huber; plus a forward-looking hazard target |
| Checkpoint selection invalid | Branch A val loss not comparable across epochs; DeepOP selected on the Benign prior | composite (macro F1 + AUC); DeepOP free-running macro F1 |
| Parity check vacuous | compared 15 of 27 dims against themselves | now compares two genuinely different paths |
| DeepOP smoothing | 2.4% of mass on 6 tokens that never occur | smoothing restricted to reachable tokens |
| Validation oversampled (DeepOP) | every val number read at an inflated attack rate | eval split not oversampled |

Full detail: reports 21–30 in this directory.
